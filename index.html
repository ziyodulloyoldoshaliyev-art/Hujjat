Qisqartma hujjatlari

Qisqartma uzun URL manzillarni qisqa havolaga aylantiruvchi xizmat. Havola necha marta ochilganini ham ko'rsatadi.

Xizmatdan veb-sayt orqali yoki o'z dasturingizdan API orqali foydalanishingiz mumkin. Bu hujjat o'rnatish, ishlatish va API haqida qisqacha tushuntiradi.

Bu namunaviy loyiha. Hujjat tuzilishi har qanday dastur uchun mos keladi.

O'rnatish

Dastur Node.js 18 yoki undan yuqori versiyani talab qiladi.

1. Loyihani yuklab oling

git clone https://github.com/misol/qisqartma.git
cd qisqartma

2. Kutubxonalarni o'rnating

npm install

3. Serverni ishga tushiring

npm start

Server http://localhost:3000 manzilida ochiladi.

Foydalanish

Asosiy sahifadagi maydonga uzun havolani kiriting va Qisqartirish tugmasini bosing. Tayyor havola nusxalash uchun pastda chiqadi.

Sozlamalar

Sozlamalar .env faylida saqlanadi.

NomiStandartTavsif
PORT3000Server porti
BASE_URLhttp://localhost:3000Qisqa havolaning bosh manzili
EXPIRE_DAYS365Havola necha kun amal qiladi

API

Barcha so'rovlar JSON formatida ishlaydi. Manzil: https://api.qisqartma.uz/v1

POST /links

Yangi qisqa havola yaratadi.

curl -X POST https://api.qisqartma.uz/v1/links \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/juda/uzun/manzil"}'

Javob:

{
  "id": "a1b2c3",
  "short": "https://qsq.uz/a1b2c3",
  "clicks": 0
}

GET /links/:id

Havola ma'lumotini va ochilganlar sonini qaytaradi.

curl https://api.qisqartma.uz/v1/links/a1b2c3

DELETE /links/:id

Havolani o'chiradi. Muvaffaqiyatli bo'lsa 204 kodi qaytadi.

FAQ

Qisqa havola muddati tugaydimi?

Standart holatda 365 kun amal qiladi. Muddatni EXPIRE_DAYS sozlamasi bilan o'zgartirish mumkin.

Havolani o'zgartirsa bo'ladimi?

Yo'q. Havolani o'chirib, yangisini yaratish kerak.

Xizmat bepulmi?

Ha, dastur ochiq kodli va bepul ishlatiladi.

Xato topsam nima qilaman?

GitHub'dagi loyiha sahifasida Issue oching va muammoni yozing.

Hech narsa topilmadi. Boshqa so'z bilan urinib ko'ring.
